# Warawara neutral artwork handoff — candidate v1

This package contains one user-approved-direction artwork *candidate* generated by ChatGPT. It has transparent alpha and is not a licensed official film asset. The user should approve the final rendered image in the actual app.

Files:
- warawara_neutral_source.png : unchanged original 1254 x 1254 RGBA generation
- warawara_neutral_1024.png : normalized transparent 1024 x 1024 canvas with safe margins
- warawara_neutral_512.png : normalized transparent 512 x 512 canvas for lighter preview/testing

Instructions for OpenCode:
1. Inspect the current Phase 4 ASSET_HANDOFF.md and existing sprites.json schema BEFORE copying files.
2. Import warawara_neutral_1024.png as the **neutral/idle** candidate according to the actual manifest, respecting logical canvas, body bounding box and anchor. Never assume this staging filename is the required production filename.
3. Reuse the same sprite for companions through existing size-scaling logic.
4. Keep existing non-neutral sprites as explicit placeholders until supplied with approved matching art. Do not redraw or replace this artwork using procedural ellipses.
5. Verify transparency, no clipping, unchanged click/hit region, velocity deformation and screen geometry.
6. Run existing preview generation / CI; provide new contact sheets for user review. Do not merge Phase 4 into main without approval.

Art workflow: ChatGPT generates/edits artwork -> user downloads and supplies PNG to OpenCode -> OpenCode integrates using the manifest -> user reviews previews and M1 Air -> refine artwork with ChatGPT and repeat.
